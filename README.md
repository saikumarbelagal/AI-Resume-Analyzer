# 🤖 AI-Powered Resume Analyzer

An intelligent resume analysis application built using Python and Streamlit. It helps job seekers evaluate their resumes against job descriptions using ATS-style keyword matching, technical skill detection and education matching.

## 🚀 Features

- 📄 Upload resumes in PDF format.
- 🔍 Extract text from PDF resumes.
- 💻 Automatically detect technical skills.
- 🎯 Compare resumes with job descriptions.
- 📊 Calculate an overall ATS-style match score.
- ✅ Identify matched skills.
- ⚠️ Detect missing skills.
- 💡 Provide personalized improvement suggestions.
- 📥 Download resume analysis reports.

## 🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Regular Expressions

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/saikumarbelagal/AI-Resume-Analyzer.git
```

2. Navigate to the project directory:

```bash
cd AI-Resume-Analyzer
```

3. Install dependencies:

```bash
pip install streamlit pymupdf scikit-learn
```

4. Run the application:

```bash
python -m streamlit run app.py
```

5. Open the application in your browser:

```text
http://localhost:8501
```

## 📊 How It Works

1. Upload your resume in PDF format.
2. The application extracts resume text.
3. Technical skills are detected automatically.
4. Paste the desired job description.
5. Click Analyze Resume.
6. View your ATS-style score and skill matching results.
7. Download your analysis report.

## 🎯 Project Objective

To develop an AI-assisted resume analysis platform that helps candidates understand how closely their resumes align with job requirements and identify areas for improvement.
